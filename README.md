# Forward Base Command

Current playable campaign: [Leipalingis map, controls, data attribution and testing](docs/leipalingis-map.md).

Design a real-time strategy (RTS) game set in modern-day warfare, combining city/base-building mechanics inspired by Stronghold: Definitive Edition with tactical military combat systems.

🧱 Core Gameplay Mechanics

 The player builds and manages a modern military settlement instead of a medieval castle.

 Replace castles with:

 Forward Operating Bases (FOBs)

 Trenches and defensive lines

 Bunkers and reinforced structures

 Urban strongpoints (abandoned buildings, factories)

 Include resource management:

 Fuel (vehicles, aircraft)

 Ammunition

 Supplies (food, morale, logistics)

 Electricity (for radar, drones, defenses)

 Civilian/workforce system similar to Stronghold:

 Engineers (build structures)

 Logistics units (supply transport)

 Medics (unit recovery & morale)

⚔️ Combat System

 Combined arms warfare:

 Infantry (riflemen, special forces, anti-tank squads)

 Armored units (tanks, APCs, IFVs)

 Artillery (howitzers, rocket systems)

 Air units (helicopters, jets)

 Tactical features:

 Cover system (trenches, buildings, terrain)

 Suppression mechanics

 Line-of-sight & fog of war

 Destructible environments

🚁 Modern Warfare Elements

Drones:

 Recon drones (fog of war reveal)

 Attack drones (precision strikes)

 Electronic warfare drones (jam signals)

Air support system:

 Call-in airstrikes (cooldown-based)

 Close air support (CAS)

 Strategic bombing

Advanced systems:

 Radar and detection

 Signal jamming / counter-intelligence

 Night/day cycle affecting combat

🧠 Strategic Layer

 Map control zones (territory capture system)

 Supply lines (cutting enemy logistics weakens them)

 Morale system (units retreat or fight better depending on conditions)

 Weather effects (rain, fog, night operations)

🏗️ Building System (Stronghold-inspired)

 Grid-based or free placement building

 Expandable base with:

 Barracks

 Vehicle depots

 Airfields

 Drone command centers

 Supply hubs

 Defensive construction:

 Sandbags

 Trenches (connectable network system)

 Watchtowers with modern tech (thermal vision)

🎮 Game Modes

 Campaign (modern conflicts / fictional geopolitics)

 Skirmish vs AI

 Multiplayer (PvP with base building + combat)

 Survival mode (defend against waves)

🎨 Tone & Style

 Semi-realistic (not arcade, not hardcore mil-sim)

 Clean modern UI (tactical overlays, minimap, drone view)

 Immersive battlefield atmosphere

🧩 Optional Advanced Features

 Modular base upgrades (tech tree)

 Unit customization (loadouts)

 AI commanders with distinct strategies

 Dynamic battlefield events (reinforcements, ambushes)

⚙️ Output Requirements

Provide:

 Core gameplay loop

 Key systems breakdown

 Example early-game → late-game progression

 Unique selling points (USP)

 Suggested tech stack (if applicable, e.g., Unity/Unreal)
